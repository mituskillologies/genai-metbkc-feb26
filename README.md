## 📌 About The Repository
This repository contains the programming materials, codes, and implementations conducted during the **"Generative AI and Agentic AI" Training Program** held at **MET BKC's Institute of Engineering, Nashik** in **February 2026**.

**Resources & Downloads:** [mitu.co.in/downloads](https://mitu.co.in/downloads)

## 🗂️ Course Content & File Structure

The repository includes a progressive series of Jupyter Notebooks covering foundational data science concepts to advanced Generative AI architectures. 

### Basics & Data Preprocessing
* `1numpy_MET_Jan31.ipynb` - Introduction to NumPy and array computations.
* `2Pandas_MET_Jan31.ipynb` - Data manipulation and analysis using Pandas.
* `3feature_scalling_MET_Feb1.ipynb` - Techniques for feature scaling and preprocessing.

### Artificial Neural Networks (ANN) & Deep Learning Foundations
* `4Perceptron_MET_Feb1.ipynb` - Introduction to Perceptrons.
* `4Activation_Functions_1Feb.ipynb` - Exploring different activation functions in Neural Networks.
* `4ANN_tensorflow.ipynb` - Building Artificial Neural Networks using TensorFlow/Keras.

### Computer Vision
* `5 Image_basics_Feb2.ipynb` - Fundamentals of working with image data.
* `6 CNN_CFAR10.ipynb` - Convolutional Neural Networks (CNNs) implemented on the CIFAR-10 dataset.
* `7 fashion_mnist_MET_Feb2.ipynb` - Image classification on the Fashion MNIST dataset.

### NLP & Sequential Models
* `8 Unstructured_Data_FEB2.ipynb` - Handling unstructured textual data.
* `9word_embeddings_word2vec.ipynb` - Word embeddings using Word2Vec.
* `10 Bi_rnn_sentiment.ipynb` - Sentiment analysis using Bidirectional Recurrent Neural Networks (Bi-RNNs).
* `11 LSTM_GRU.ipynb` - Advanced sequential modeling with LSTMs and GRUs.

### Generative AI & Transformer Models
* `12 Encoer-decoder.ipynb` - Understanding Encoder-Decoder architectures.
* `13 huggingface_Transformers.ipynb` - Introduction to Hugging Face Transformers.
* `14 Gpt_sample_textgen.ipynb` - Text generation using GPT models.
* `15 Transformers_huggingface.ipynb` - Advanced applications and fine-tuning with Hugging Face Transformers.
